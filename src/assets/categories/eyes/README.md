# Eyes Assets - Specifications

Este directorio debe contener las imágenes de ojos para la aplicación Bambole.

## Archivos Requeridos

### Eyes-1: Ojos Redondos

**Icon (eyes-1_icon.png)**

- Dimensiones: 100x100px
- Formato: PNG con transparencia
- Contenido: Dos círculos negros simples representando ojos redondos
- Fondo: Transparente
- Estilo: Minimalista, similar a los íconos de nose y ears

**Preview (eyes-1_prev.png)**

- Dimensiones: Igual que las imágenes de character (aproximadamente 400x600px)
- Formato: PNG con transparencia
- Contenido: Dos ojos redondos posicionados donde irían en la cabeza del personaje
- Posición: Entre las vueltas 15-16 de la cabeza, con 8-10 puntos de separación
- Fondo: Transparente
- Nota: Los ojos deben estar posicionados para alinearse correctamente cuando se superpongan sobre character-1.png y character-2.png

### Eyes-2: Ojos Ovalados

**Icon (eyes-2_icon.png)**

- Dimensiones: 100x100px
- Formato: PNG con transparencia
- Contenido: Dos óvalos negros representando ojos ovalados
- Fondo: Transparente
- Estilo: Minimalista, similar a los íconos de nose y ears

**Preview (eyes-2_prev.png)**

- Dimensiones: Igual que las imágenes de character (aproximadamente 400x600px)
- Formato: PNG con transparencia
- Contenido: Dos ojos ovalados posicionados donde irían en la cabeza del personaje
- Posición: Entre las vueltas 14-17 de la cabeza, con 9-11 puntos de separación
- Fondo: Transparente
- Nota: Los ojos deben estar posicionados para alinearse correctamente cuando se superpongan sobre character-1.png y character-2.png

## Herramientas Sugeridas

- Adobe Photoshop
- GIMP (gratuito)
- Figma (online)
- Canva (online)
- Procreate (iPad)

## Proceso de Creación

1. Abrir las imágenes de referencia: character-1.png y character-2.png
2. Crear una nueva capa con las mismas dimensiones
3. Dibujar los ojos en la posición correcta
4. Exportar solo la capa de ojos con fondo transparente
5. Para los íconos, crear versiones simplificadas de 100x100px

## Estilo Visual

Mantener consistencia con:

- src/assets/categories/nose/nose-1_icon.png
- src/assets/categories/ears/ears-1_icon.png

Los ojos deben ser simples, claros y fácilmente reconocibles en tamaño pequeño.
